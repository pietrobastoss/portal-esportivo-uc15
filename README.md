# Portal Esportivo — Temporada em Jogo

Projeto desenvolvido para a UC15 — HTML Mobile First, com foco em design responsivo, acessibilidade e boas práticas de desenvolvimento web.

## Objetivo

Desenvolver um portal esportivo que apresente notícias, calendário de jogos, classificação, galeria de imagens e funcionalidades interativas, priorizando a experiência em dispositivos móveis.

## Tecnologias previstas

* HTML5 semântico
* CSS3, Flexbox, Grid e Container Queries
* JavaScript
* Bootstrap 5.3
* jQuery 4
* WordPress com tema filho
* Ferramentas de testes de acessibilidade, desempenho e automação

## Estrutura do projeto

* `prototipo/`: versão desenvolvida com HTML, CSS e JavaScript.
* `wordpress/tema-filho/`: arquivos do tema filho do WordPress.
* `tests/`: testes automatizados.
* `docs/`: evidências e relatório final.
* `DECISOES.md`: decisões técnicas e justificativas.
* `TESTES.md`: procedimentos e resultados dos testes.
* `CMS.md`: configuração e documentação do WordPress.
