# Relatório final — UC15

## Objetivo

Desenvolver o Temporada em Jogo, um portal esportivo sobre futebol brasileiro, com foco em responsividade, acessibilidade e facilidade de navegação, principalmente em dispositivos móveis.

## Tecnologias utilizadas

- HTML5 para a estrutura semântica das páginas.
- CSS3 para estilização, layout responsivo e efeitos visuais.
- JavaScript para interatividade e navegação.
- PHP para integração com o WordPress.
- WordPress para gerenciamento e publicação de conteúdos.
- Git e GitHub para controle de versão e armazenamento do código.
- XAMPP para executar o WordPress localmente.

## Funcionalidades implementadas

- Menu de navegação responsivo com opção de abrir e fechar em dispositivos móveis.
- Navegação por seções: Início, Notícias, Jogos e Classificação.
- Destaque da seção ativa na navegação.
- Exibição dinâmica de notícias e jogos cadastrados no WordPress.
- Exibição da classificação com tabela de posições, equipes e pontos.
- Abertura das publicações ao clicar em seus títulos.
- Organização do código em arquivos separados para estrutura, estilos, scripts e integração com o WordPress.
- Ajustes de acessibilidade, incluindo foco visível e respeito à preferência por movimento reduzido.

## Testes realizados

Foram realizados testes manuais durante o desenvolvimento, incluindo:

- Verificação do menu em dispositivos móveis.
- Verificação dos links e da navegação entre as seções.
- Testes de responsividade nas larguras de 320 px, 375 px, 768 px e 1024 px.
- Verificação da exibição de notícias cadastradas no WordPress.
- Verificação da exibição dos jogos cadastrados na categoria correspondente.
- Verificação da tabela de classificação.
- Ajustes na apresentação dos parágrafos das publicações de jogos.

Os testes automatizados e uma auditoria completa de acessibilidade e desempenho ainda precisam ser verificados antes da entrega final.

## Acessibilidade e desempenho

O projeto utiliza elementos semânticos do HTML, atributos de acessibilidade na navegação, foco visível para interação por teclado e uma regra CSS para respeitar a preferência por movimento reduzido.

Também foram realizados ajustes para melhorar a experiência em diferentes tamanhos de tela. Uma avaliação completa de contraste, navegação por teclado, desempenho e outros critérios de acessibilidade ainda está pendente.

## Publicação

O portal está integrado ao WordPress e funciona em ambiente local por meio do XAMPP. O código-fonte está versionado no Git e armazenado no GitHub.

A publicação em um servidor acessível pela internet ainda não foi realizada.

## Limitações conhecidas

- O conteúdo de demonstração utiliza informações fictícias.
- A classificação apresentada na página inicial utiliza equipes e pontuações definidas no código PHP, não sendo atualizada automaticamente a partir de resultados reais.
- O funcionamento do WordPress depende do ambiente local configurado.
- Ainda são necessárias verificações finais de acessibilidade, desempenho e documentação das evidências.

## Conclusão

O desenvolvimento do Temporada em Jogo permitiu aplicar conhecimentos de HTML, CSS, JavaScript, PHP, WordPress e controle de versão com Git. O projeto evoluiu de um protótipo responsivo para um portal integrado ao WordPress, com gerenciamento de notícias e jogos. Os testes realizados ajudaram a identificar e corrigir problemas de navegação, responsividade e apresentação do conteúdo. Como próximos passos, é necessário concluir as verificações finais, organizar as evidências e conferir os requisitos da entrega.
